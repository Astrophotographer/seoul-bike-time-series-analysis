# 서울시 따릉이 시계열 분석 프로젝트 설계

- 작성일: 2026-09-30
- 상태: 사용자 승인 완료 설계안
- 프로젝트 유형: 시계열 데이터 분석 리포트

## 1. 목적과 성공 기준

이 프로젝트의 목적은 2023~2024년 서울시 따릉이 일별 이용량을 분석해 시간에 따른 추세, 주간·월간 계절성, 날씨와의 관계, 이상 구간을 근거와 함께 설명하는 것이다.

최종 결과물은 다음 기준을 만족해야 한다.

- 100개 이상의 일별 시계열 데이터 포인트를 사용한다.
- 분석 질문을 3개 이상 정의하고, 질문별로 관찰과 해석을 구분한다.
- 이동평균, 구간별 집계, 변화율·변동성 등 2가지 이상의 시계열 분석 방법을 적용한다.
- 리포트에 시각화 3개 이상과 수치 근거가 있는 인사이트 3개 이상을 포함한다.
- 원본 데이터 출처, 수집 방법, 의존성, 실행 방법, AI 사용 로그를 남긴다.
- 날씨와 이용량의 관계를 인과관계로 단정하지 않고 상관관계와 가능한 가설로 설명한다.

## 2. 분석 범위

### 포함 범위

- 주 분석 대상: 서울시 전체 따릉이 일별 이용건수
- 분석 기간: 2023-01-01 ~ 2024-12-31
- 보조 변수: 서울 중심 좌표 인근 격자의 일평균기온과 일강수량
- 핵심 분석 단위: 날짜 1개당 1개 행
- 기본 분석 언어·도구: Python, pandas, NumPy, Matplotlib, Seaborn
- 심화 옵션: `statsmodels`의 STL 분해

### 제외 범위

- 개별 대여소의 공간 분포 분석
- 시간대별 수요 예측 모델 비교
- 외부 사건의 인과효과 추정
- 실시간 API 서비스나 배포형 대시보드

개별 대여소·시간대 분석은 데이터 처리량과 해석 범위를 크게 늘리므로 이번 결과물의 핵심 범위에서 제외한다. 대시보드는 보너스 요구사항이며, 핵심 리포트 완성 후 여유가 있을 때만 추가한다.

## 3. 접근 방식과 선택 이유

### 선택한 접근: 일별 이용량 + 날씨 보조 데이터

따릉이 원본을 날짜별로 집계한 뒤 기상청의 일별 기온·강수량을 날짜 기준으로 결합한다. 이 방식은 하나의 명확한 주 시계열을 유지하면서도 “날씨가 다른 날에 이용량이 어떻게 달라지는가?”라는 해석 질문을 추가할 수 있다.

### 대체 접근

1. **따릉이 단일 시계열**
   - 장점: 데이터 결합이 단순하고 재현성이 높다.
   - 단점: 급등·급락의 원인 해석이 날짜와 계절에 대한 가설 수준에 머물 수 있다.
   - 사용 조건: 기상 데이터 다운로드나 지점 매칭이 불가능할 때 fallback으로 사용한다.

2. **시간대·대여소 세분화**
   - 장점: 출퇴근·여가 패턴을 더 구체적으로 분석할 수 있다.
   - 단점: 전처리량과 시각화 복잡도가 커지고 전체 과제 범위를 벗어날 가능성이 있다.
   - 결정: 이번 버전에서는 제외한다.

## 4. 데이터 출처와 데이터 계약

### 4.1 따릉이 데이터

- 출처: 서울 열린데이터광장, [서울시 공공자전거 따릉이 이용현황](https://data.seoul.go.kr/dataList/OA-14994/F/1/datasetView.do)
- 선택 파일: 2023년 상반기·하반기, 2024년 상반기·하반기 일별 대여건수 파일
- 사용할 컬럼: 대여일자, 대여건수
- 집계 방식: 서울시가 제공하는 서울시 전체 일별 대여건수를 날짜별 시계열로 사용한다.
- 인코딩: 서울시 원본의 CP949 계열 인코딩을 UTF-8·CP949·EUC-KR 순으로 시도한다.
- 원본 보존: 원본 파일은 `data/raw/`에 저장하거나, 파일이 큰 경우 `data/README.md`에 다운로드 주소와 파일명을 기록한다.

### 4.2 기상 데이터

- 출처: [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api)
- 대상 위치: 서울 중심 좌표 `37.5665, 126.9780`을 질의해 반환된 서울 인근 격자
- 사용할 컬럼: 날짜, `temperature_2m_mean`, `precipitation_sum`
- 결합 방식: 날짜를 키로 하는 left join
- 보조 데이터가 없는 날짜는 임의로 0이나 평균값으로 채우지 않고 결측으로 남긴다.
- 기상 데이터는 격자 기반 보조 자료이므로 서울 관측소의 공식 계측값과 동일하다고 해석하지 않는다.

### 4.3 라이선스와 출처 표기

리포트와 README에 각 데이터셋의 제공기관, 원본 URL, 다운로드 시점, 사용한 컬럼, 이용조건 확인 여부를 기록한다. GitHub에는 대용량 원본 전체를 무조건 포함하지 않고, 재수집 방법과 정제 결과를 함께 제공한다.

## 5. 분석 질문과 분석 방법

### 질문 1. 전체적인 이용 추세가 있었는가?

- 일별 이용량 선그래프를 날짜 순으로 표시한다.
- 7일 이동평균을 추가해 주간 노이즈를 완화한다.
- 초반·후반 구간의 평균과 중앙값을 비교한다.
- 이동평균의 변화만으로 장기 원인을 단정하지 않는다.

### 질문 2. 요일과 월에 따른 계절성이 있는가?

- 요일별 평균·중앙값을 계산한다.
- 월별 평균·중앙값을 계산한다.
- 월 × 요일 평균을 히트맵으로 표시한다.
- 평균만으로 특정 요일의 모든 날짜가 높다고 해석하지 않고, 중앙값과 분포도 함께 확인한다.

### 질문 3. 날씨와 이용량은 어떤 관계를 보이는가?

- 강수량이 0인 날과 0보다 큰 날의 이용량을 비교한다.
- 평균기온을 구간으로 나누어 이용량 분포를 비교한다.
- 기온·강수량과 이용량의 Spearman 상관계수를 참고한다.
- 날씨 비교는 관찰된 연관성으로만 표현하며, 휴일·방학·대여소 공급량 등 다른 요인을 통제하지 않았다는 점을 명시한다.

### 질문 4. 급격한 변화나 이상 구간은 언제인가?

- 전일 대비 변화율을 계산한다.
- 7일 이동평균 대비 편차와 이동 표준편차를 이용해 후보 구간을 표시한다.
- 이상값 후보를 자동 삭제하지 않고 원본 행·날짜·날씨·요일을 확인한다.

### 심화 옵션

핵심 결과가 완성된 후 `period=7`인 STL 분해를 적용해 추세, 주간 계절성, 잔차를 시각화한다. 분해 결과는 예측 정확도 결과가 아니라 시계열 구성요소를 해석하는 보조 근거로 사용한다.

## 6. 데이터 정제 규칙

1. 날짜 컬럼을 날짜형으로 변환하고, 분석 기간 밖의 행을 제외한다.
2. 이용건수를 숫자형으로 변환하며 변환 실패 행을 별도 기록한다.
3. 완전히 동일한 원본 행은 중복으로 간주해 제거하고 제거 건수를 출력한다.
4. 대여일자별로 이용건수를 합산해 일별 데이터셋을 만든다.
5. 날짜 캘린더와 비교해 누락 날짜를 확인한다. 원본에 기록이 없다는 이유만으로 해당 날짜의 이용량을 0으로 채우지 않는다.
6. 합리적인 범위를 벗어난 음수 이용건수나 숫자 변환 실패값은 오류로 분리한다.
7. 통계적 이상치는 robust z-score 또는 IQR 기준으로 표시만 하고, 실제 운영상의 급증일 수 있으므로 기본적으로 삭제하지 않는다.
8. 변화율 계산의 첫 날짜처럼 계산 불가능한 행은 분석별로 제외하고 사유를 리포트에 기록한다.
9. 날씨 결합 후 기온·강수량 결측 비율을 확인하고, 날씨 관련 분석에서는 유효한 행만 사용한다.

## 8. 실행·검증 전략

분석 스크립트는 원본 데이터를 읽고 정제된 일별 CSV와 이미지 파일을 생성한다. 다음 항목을 실행 중 검증한다.

- 최종 일별 행 수가 100개 이상인지
- 날짜가 오름차순인지
- 일별 집계 후 날짜 중복이 없는지
- 이용건수가 음수가 아닌지
- 기상 데이터 결합 후 결측 비율이 출력되는지
- 이미지 3개 이상이 생성되는지
- 리포트의 숫자가 실행 결과와 일치하는지

실제 데이터 다운로드가 필요한 부분은 자동 수집 API에 과도하게 의존하지 않고, 원본 파일을 `data/raw/`에 둔 뒤 분석을 재실행할 수 있는 구조를 우선한다. 원본 파일을 포함하지 못하는 경우에는 파일명·URL·다운로드 날짜를 명시한다.

## 9. 주요 한계

- 전체 서울시 이용량만 분석하므로 대여소별·지역별 차이를 설명하지 못한다.
- 날씨와 이용량의 관계는 관찰 연구이며 인과관계를 증명하지 않는다.
- 공휴일, 학교 방학, 행사, 자전거 공급량, 대여소 운영 장애를 모두 통제하지 않는다.
- 월별 원본 파일의 기록 방식과 기상 관측 지점의 대표성이 결과에 영향을 줄 수 있다.
- 2023~2024년만 사용하므로 장기 기후 변화나 정책 변화까지 일반화하기 어렵다.
