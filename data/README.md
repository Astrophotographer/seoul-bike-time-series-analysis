# 데이터 수집 안내

## 따릉이 원본

서울 열린데이터광장의 [서울시 공공자전거 따릉이 이용정보(월별)](https://data.seoul.go.kr/dataList/OA-15248/A/1/datasetView.do)에서 다음 파일을 내려받아 `data/raw/bike/`에 저장한다.

- `서울특별시_공공자전거 이용정보(월별)_23.1-6.csv`
- `서울특별시_공공자전거_이용정보(월별)_23.7-12.csv`
- `서울특별시 공공자전거 이용정보(월별)_24.1-6.csv`
- `서울특별시 공공자전거 이용정보(월별)_24.7-12.csv`

분석에 사용하는 원본 컬럼은 `대여일자`와 `이용건수`이며, 대여소별 행을 날짜별로 합산한다. 원본 파일은 용량과 이용조건을 확인한 뒤 GitHub에 포함하거나, 포함하지 않는 경우에도 이 문서와 공식 URL을 함께 배포한다.

## 기상 원본

[기상청 기상자료개방포털 조건별통계](https://data.kma.go.kr/climate/RankState/selectRankStatisticsDivisionList.do)에서 서울 관측 지점 108번의 2023-01-01~2024-12-31 일별 자료를 내려받는다. 평균기온과 일강수량을 포함한 CSV로 저장하고 파일명을 `data/raw/weather_seoul_108.csv`로 맞춘다.

기상청 다운로드 파일의 컬럼명은 export 형식에 따라 달라질 수 있다. 분석 코드는 다음 의미의 컬럼을 자동으로 표준화한다.

- 날짜 → `date`
- 평균기온 → `mean_temp_c`
- 일강수량 → `precip_mm`

## 출처·이용조건 기록

- 다운로드 시점: 2026-09-30
- 제공기관: 서울특별시, 기상청
- 원본 URL과 사용 컬럼은 위 링크에서 확인한다.
- 제출 전 각 사이트의 최신 이용허락·출처표기 조건을 다시 확인한다.
